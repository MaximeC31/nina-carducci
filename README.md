# Nina Carducci

Site portfolio pour photographe professionnelle, optimisé pour les performances et le référencement (SEO).

## Description du projet

Ce projet consiste à optimiser les performances et le référencement (SEO) du site d'une photographe professionnelle tout en corrigeant des bugs existants. Le site a été entièrement codé from scratch en HTML/CSS/JavaScript avec les améliorations suivantes :

-   **Optimisation des performances** : Utilisation de Lighthouse et Wave pour analyser et améliorer les performances du site
-   **Référencement local** : Implémentation de Schema.org et optimisation des métas pour les réseaux sociaux (Open Graph et Twitter Cards)
-   **Accessibilité** : Améliorations pour une meilleure accessibilité web
-   **Images optimisées** : Utilisation de formats WebP avec différentes tailles (480px, 720px, 1080px) pour le responsive
-   **Gallery interactive** : Système de filtrage par catégories (Concerts, Entreprises, Mariages, Portraits) avec lightbox

## Comment le démarrer

Ce projet est un site statique HTML/CSS/JavaScript. Pour le lancer, il est recommandé d'utiliser un service comme l'extension Live Server dans VSCode :

1. Installez l'extension Live Server dans VSCode si ce n'est pas déjà fait
2. Ouvrez le dossier du projet dans VSCode
3. Clic droit sur `index.html` et sélectionnez "Open with Live Server". Cela lancera un serveur local (généralement sur http://127.0.0.1:5500)
